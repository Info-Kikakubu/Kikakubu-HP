# Webサイト変更仕様書

## 1. 目的

スマートフォンとPCの両方で閲覧できる、シンプルで親しみやすい情報案内サイトを構築する。

訪問者がトップ画面から主要コンテンツを直感的に選択でき、必要に応じて詳細情報を段階的に確認できることを重視する。

## 2. 重視するポイント

- スマートフォンとPCの両方で使いやすいレスポンシブデザイン
- 情報を一度に表示しすぎず、モーダルと折りたたみメニューで段階的に提示する
- タップまたはクリックできる場所を視覚的に分かりやすくする
- コンテンツの追加や文章変更を簡単に行えるデータ構造
- 既存の情報はすべて残す。この仕様書に書いていない情報はすべて詳細情報の場所に詰めておく。

## 3. ページ構成

ページは上から次の順番で構成する。

### 3.1 タイトルエリア

- 日本語のメインタイトル
- サイトの内容を簡潔に伝える説明文

### 3.2 メインカード

正方形のカードを4つ表示する。

- スマートフォン：2列
- PC：4列
- 各カードはタップ・クリック可能
- 選択すると詳細モーダルを表示
- ホバー可能な端末では、浮き上がりと上部アクセントラインを表示

カードはデー祭が行う大学祭のイベントごとに用意する。これは初めて企画を知った人が企画をすっと理解できるようにすること。

### 3.3 詳細情報

メインカードの下に、4つの折りたたみ式メニューを表示する。

各項目には次の情報を格納できる。

- 項目番号
- タイトル
- 短い補足文
- 詳細説明
- 複数の補足タグ

項目については、仕様書で明記されていないもののすでに実装済みの情報を格納する項目を用意すること。

折りたたみメニューは複数項目を同時に開ける仕様とする。

### 3.4 固定クイックメニュー

画面右下に2つの円形ボタンを固定表示する。

- SNSボタン
- 地図・アクセスボタン

どちらもタップ・クリックすると専用の詳細モーダルを表示する。

メインコンテンツと重ならないよう、ページ下部には十分な余白を設ける。

## 4. モーダル仕様

メインカード、SNSボタン、地図ボタンから共通形式のモーダルを開く。

### 表示内容

- アクセントカラー
- 補助タイトル
- 見出し
- 詳細説明
- 閉じるボタン

### 操作

- 閉じるボタンで閉じる
- モーダル外の背景をクリックして閉じる
- `Escape`キーで閉じる
- モーダル表示中は背景ページのスクロールを停止する
- モーダルを開いたときは閉じるボタンへフォーカスを移動する

### 表示形式

- スマートフォン：画面下から表示するボトムシート形式
- PC：画面中央に表示するダイアログ形式

## 5. レスポンシブ仕様

### スマートフォン

- 横方向の余白を小さめにする
- メインカードは2列
- タイトル文字を画面幅に合わせて縮小
- モーダルは画面下部に密着
- 詳細情報の補足文は一部省略し、見出しを優先

### PC

- コンテンツの最大幅を設定し、中央配置
- メインカードは4列
- タイトルを大きく表示
- モーダルは中央配置
- 詳細情報の補足文とコピーライトを表示

## 6. デザイン方針

- 現在のまま変更しない。

## 7. アクセシビリティ

現在のデザインの基本方針に反しない限り以下を実行する

- 操作要素には内容が分かるラベルを付ける
- モーダルには`dialog`と`aria-modal`を設定する
- セクションには適切な見出しまたはラベルを設定する
- キーボードのフォーカス位置を視覚的に表示する
- 色だけに依存せず、文字や形でも状態を伝える
- OSで動きを減らす設定が有効な場合は、アニメーション時間を最小化する
- タップ対象は十分な大きさを確保する

## 8. 実装構成

現在の使用構成で不足するものを補う形で実装すること。

## 9. コンテンツ編集方法

別環境で動かしたときのメモが以下の通り。現環境では以下の内容が編集できるようになる場所を用意して以下を実装すること。

### メインカードとモーダル

`src/App.tsx`内の`panels`配列を編集する。

各データは次の形式：

```ts
{
  id: '一意のID',
  eyebrow: '補助タイトル',
  title: '見出し',
  description: '詳細説明',
  accent: 'Tailwind CSSの背景色クラス',
}
```

### 詳細情報

`src/App.tsx`内の`additionalInfo`配列を編集する。

各データは次の形式：

```ts
{
  number: '表示番号',
  title: '見出し',
  lead: '短い補足文',
  body: '詳細説明',
  notes: ['補足タグ1', '補足タグ2'],
}
```

配列に項目を追加すると、折りたたみメニューにも自動的に追加される。

### SNS・地図

- SNS情報：`snsPanel`
- 地図・アクセス情報：`mapPanel`

住所やSNSリンクが確定した場合は、このデータとモーダル内容を更新する。

## 10. 今後の拡張時の注意

- 外部リンクを追加する場合は、新しいタブで開くかを明確にし、リンク先が分かる文言を使用する
- Google Mapsなどを埋め込む場合は、表示速度とプライバシー同意を考慮する
- 情報量が大幅に増える場合は、`App.tsx`からデータとコンポーネントを別ファイルへ分割する
- CMSや管理画面から更新する必要が生じた場合は、静的配列を外部データに置き換える
- 既存のレスポンシブ表示、モーダル操作、アクセシビリティを維持する

## 11. 完了条件

- スマートフォンとPCでレイアウトが崩れない
- 4つのメインカードから各モーダルを開ける
- 4つの詳細情報を開閉できる
- SNSと地図の円形ボタンから各モーダルを開ける
- モーダルをボタン、背景クリック、`Escape`キーで閉じられる
- キーボード操作時にフォーカス位置が確認できる
- `pnpm build`がエラーなく完了する
