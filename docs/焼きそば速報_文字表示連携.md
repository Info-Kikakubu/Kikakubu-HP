# 焼きそば速報の文字表示

ゴシック太字の2行に「準備中」「受け取り出来ます」を表示し、数字を大きくします。単位は利用者の指定により「人」です。ただし元データは整理券・注文の件数で、注文数量を人数に換算するものではありません。

## 公開前の必須作業

まちベルの実際の公開版で、GET /api/board の応答だけに以下のCORSヘッダーを付け、デプロイ後に確認してください。

- Access-Control-Allow-Origin: https://info-kikakubu.github.io
- Vary: Origin（既存のVaryがある場合は追加）

公開boardデータの読み取りに限定します。スタッフAPIの認証・Origin検証、Cookie、注文データは変更しません。HPは credentials: omit のGETで取得し、追加ヘッダーを送らないためプリフライトは不要です。

2026-10-31時点で公開APIはこのCORSヘッダーを返していません。対応前に本PRをマージすると数値を取得できません。関連リポジトリ Asukiyo/food_court_system の内容は公開版より古いため、そのままデプロイしないでください。実際の公開版のコードを確認してから適用してください。

## 同期内容

- 準備中: 対象店舗 cooking の件数
- 受け取り出来ます: calling と pickup（未定義時は tickets）の番号を重複排除した件数
- 約2秒ごとに更新。非表示タブでは停止し、表示復帰・オンライン復帰時に再確認
- 通信失敗・不正データは0人にせず「—」と案内を表示
- 元画面へのリンクを維持
